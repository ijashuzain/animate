# Prompt — Procedural graphics/animation engineer

Given reviewed pattern records and a new original subject brief, create an editable source-code asset and rig — not a generated raster illustration and not a traced reference.

Requirements:
- SVG paths, nested groups, procedural Bézier profiles, gradients/masks, deliberate depth ordering, explicit semantic component IDs.
- Parametric anatomy, scene scales, original palette, readable thumbnail silhouette, coherent lighting/shadow and meaningful detail variation.
- Rig controls with pivot and named actions, deterministic frame-based interpolation, meaningful secondary motion.
- Include still preview at rest and two extreme poses, 4–8s animation test, source and parameter schema, render command.
- Describe original design choices independent of any named creator or reference frame.
- Add A/B experiment relative to own baseline; include failures and QA measurements.

Never assert professional parity until benchmark/human evaluation supports it.
