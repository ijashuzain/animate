# Repository licensing decision required

No single license has been selected for the future GitHub repository. Select one before publication, considering the distinction between **original code**, **original artwork/renders**, **non-copyrightable analytical facts**, and **third-party reference materials**.

Do not assign an open-source license to material you do not own or have rights to redistribute. Do not include protected reference frames or audiovisual works in the public repository without permission.

Review each dependency's license separately (notably Remotion, which has its own terms). A GitHub repository's public visibility does **not** mean all included works have been licensed for reuse.
